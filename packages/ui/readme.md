### Install

Install `@maily-to/ui` from your command line.

```sh
pnpm add @maily-to/ui
```

### Overview

This package provides the low-level UI primitives used by the Maily editor, including:

- **Condition builder** — visual builder for show-if / repeat conditions
- **Unit field** — compound component for numeric inputs with unit selection (e.g. `px`, `%`)
- **Hooks** — `useMergeRefs`, `useValueAsRef`, and more
- **Utilities** — helper functions shared across UI components

Built on top of [Base UI](https://base-ui.com) and [Floating UI](https://floating-ui.com).
